# Интерфейс и UX

- Перед изменением интерфейса посмотри реальное окно игры и HUD целиком. Камера может пропустить слой Screen Space Overlay.
- Сохраняй художественное направление. Согласованно улучшай иерархию, контраст, отступы, типографику и отклик на действия.
- Сохраняй обработчики кнопок и игровые привязки. При правке стиля меняй нужные элементы существующего Canvas или UI Toolkit.
- Оставляй важную игровую область видимой. Выделяй основные действия, объясняй причины недоступности и оставляй удобные зоны нажатия для касаний.
- Проверяй целевые размеры экранов и сенсорное управление. Учитывай масштабирование мировых элементов и экранного HUD отдельно.

## Локализация

- Используй именованные константы из `LocalizationKeys`. Повторно используй ключ, если текст выполняет ту же задачу.
- Храни переводы и шаблоны в коллекции Unity Localization `Game UI`. Добавляй новые ключи в русскую и английскую таблицы, используй `l10n-<key>` для текста UXML и `l10n-tip-<key>` для подсказок.
- Вызывай `GameLocalization.Text(key)` для простого текста и `GameLocalization.Format(key, values)` для шаблонов. Передавай ключ и значения для подстановки. Резервный текст храни в тех же таблицах, резервный язык задавай в `GameLocalization.FallbackLanguage`.

Визуальные примеры и целевые размеры экранов описаны в [визуальном направлении](../VisualDirection.md).
